# Stereo miniのステレオマッチング原理

## 1. なぜ左右のカメラで同じ点が分かるのか？

Basler Stereo mini STM-502uは、左右2台のカメラで撮影した画像の「同じ場所」を探し、その位置のずれから距離を求めます。

しかし、赤外線画像には大量の白い点（ドット）が写っています。どの点も似ているため、**白い点を1個だけ見ても、左右で同じ点かどうかは判断しにくい**のです。

そこで使うのが、**周囲の模様・探す位置の制約・複数画素の整合性**です。

## 2. 点1個ではなく「周囲の模様」で照合する

ある白い点の周辺に、例えば次のような特徴があるとします。

- 左上に小さな点が2つ
- 右下に大きな点が1つ
- 中央付近には点が密集している

このような局所的な模様を、左右の画像で比較します。

```text
左画像の小領域                右画像の候補領域

  ・    ・・                    ・    ・・
     ●    ・        ⇔             ●    ・
  ・・     ●                   ・・     ●

    周囲の配置が似ている → 対応する場所の候補
```

**重要：** Stereo miniが必ず個々のドットを識別している、という意味ではありません。一般的なステレオマッチングでは、画素の明るさや局所的な模様を手がかりに対応位置を推定します。Basler内部の詳細アルゴリズムはここでは特定していません。

## 3. 画像全体を探さなくてもよい理由

左右カメラの位置関係やレンズ特性は、校正（キャリブレーション）によって把握されています。

この情報を用いて画像を補正（レクティフィケーション）すると、対応する点は基本的に**同じ高さの水平線上**に並びます。

```text
左画像                         右画像
┌────────────────┐            ┌────────────────┐
│                │            │                │
│──────●─────────│            │───●────────────│ ← 同じ行を探す
│                │            │                │
└────────────────┘            └────────────────┘
       ↑                           ↑
       左の点                      右の対応点

       横方向の位置差 = 視差 d
```

この制約を**エピポーラ拘束**と呼びます。2次元画像全体ではなく、ほぼ1次元の範囲を探せるため、誤対応を減らし、処理も効率化できます。

また、想定する撮影距離から、あり得る視差の範囲も絞り込めます。

## 4. 赤外線のランダムドットは何のため？

STM-502uは、対象物に赤外線のドットパターンを投影する**アクティブステレオ方式**です。

真っ白な板のように模様が少ない物体では、左右のどの場所が同じなのか判断しにくくなります。そこで人工的なドット模様を付けると、局所的な特徴が増え、左右画像の照合がしやすくなります。

今回確認した左右の赤外線画像に見える大量の白い点は、この仕組みを理解するためのよい実例です。

なお、**プロジェクターが各ドットの距離を直接測っているわけではありません。** 距離を求める基本原理は、左右カメラの視差を使った三角測量です。

## 5. コンピューターによる照合のイメージ

代表的な考え方として、左画像の小領域と、右画像の候補領域の明るさを比較します。

例えばSSD（差の二乗和）という評価方法では、

$$
SSD(d) = \sum_{(i,j)\in W} [L(i,j)-R(i-d,j)]^2
$$

- $L$：左画像の画素の明るさ
- $R$：右画像の画素の明るさ
- $W$：比較する小領域
- $d$：横方向のずれ（視差）

SSDが小さいほど、2つの領域が似ていると判断できます。

実際には、周囲の画素との整合性確認や誤対応の除去なども重要です。**この式は原理説明用であり、Basler製品がSSDをそのまま採用しているという意味ではありません。**

## 6. 対応点が分かれば、距離は三角測量で求められる

補正された平行ステレオカメラの基本式は次のとおりです。

$$
Z = \frac{fB}{d}
$$

| 記号 | 意味 | 単位例 |
|---|---|---|
| $Z$ | 対象物までの奥行き | mm |
| $f$ | 焦点距離（画像上の値） | pixel |
| $B$ | 左右カメラの基線長 | mm |
| $d$ | 左右画像の視差 | pixel |

STM-502uの基線長は **50 mm** です。

- 近い物体：視差が大きい
- 遠い物体：視差が小さい

例えば仮に $f=800$ pixel、$B=50$ mm、$d=200$ pixelなら、

$$
Z = \frac{800\times50}{200} = 200\ \mathrm{mm}
$$

となります。※焦点距離800 pixelは説明のための仮の値です。

## 7. なぜ3Dデータに黒い穴や欠落が生じるのか？

左右の対応位置を信頼できる精度で求められない場合、深度が無効になることがあります。

主な例：

- 金属の反射による白飛び
- 透明・半透明な物体による複雑な反射や透過
- 片方のカメラから隠れている場所（オクルージョン）
- 模様の少ない表面
- 繰り返し模様による取り違え
- 露光・投光・画像処理条件が適切でない場合

以前の3D Viewerで見られた深度データの欠落も、対応点の計算が難しくなった可能性があります。ただし、**特定の解像度だけで異常になる原因は未解明**であり、今回の原理説明だけでは断定できません。

## 8. 今後の物体位置検出との関係

Pythonで取得しているデータは、各画素に対応するXYZ座標を持つNumPy配列です。

```python
xyz.shape  # 例: (720, 1280, 3)

# 画像座標 (u, v) に対応する3次元座標
X, Y, Z = xyz[v, u]
```

物体の領域をOpenCVなどで検出し、その領域の有効なXYZ座標を使えば、物体の位置をmm単位で推定できます。

**注意：** 保存用の8bit BMPは表示しやすい反面、元の距離精度を保持していません。位置検出には元のXYZ配列を使うのが適切です。また、物体の中心をどう定義するか（画像上の中心、点群の重心など）は用途に合わせて決めます。

## 9. まとめ

Stereo miniが大量のドットから対応位置を見つけられるのは、主に次の組み合わせによります。

1. **周囲の模様を比較する**：点1個ではなく局所的な特徴を使う
2. **探索位置を限定する**：校正済みの左右画像では同じ水平線上を探せる
3. **赤外線ドットを投影する**：模様の少ない物体にも特徴を付ける
4. **一致の信頼性を確認する**：誤対応が疑われる場所は無効にできる
5. **視差から距離を求める**：基線長と焦点距離を用いて三角測量する

> **核心：** 「同じ白い点を見分ける」のではなく、「周囲の模様と幾何学的な制約を利用して、左右で対応する場所を推定する」。
