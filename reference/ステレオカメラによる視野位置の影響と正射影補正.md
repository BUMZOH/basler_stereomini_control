# ステレオカメラによる視野位置の影響と正射影補正

## 1. はじめに

通常の2Dカメラでは、同じ物体でも画像の中心と端で見え方が変わることがあります。特に高さのある部品は、視野の端では側面が見えるため、輪郭・面積・重心位置が変化します。

**ステレオカメラでも撮影時の見え方自体は変わります。しかし、取得した3D座標を使って見え方を補正できることが大きな利点です。**

## 2. 普通のカメラで見え方が変わる理由

一般的なカメラは**透視投影**で画像を作ります。

- 視野の中心では、カメラのほぼ真下から物体の上面を見る。
- 視野の端では、斜め方向から物体を見るため側面が写りやすい。
- カメラからの距離や物体の高さによって、画像上の大きさ・輪郭が変わる。

例えば円柱の上面は、真上では円に近く見えても、斜めからは楕円状に見え、側面も写ります。2D画像だけで輪郭を比較すると、同じ部品でも別の形状として扱われる可能性があります。

## 3. ステレオカメラでは何が違うのか

Basler Stereo miniのようなステレオカメラは、左右画像の対応点から奥行きを求め、各有効画素に対して3D座標 `(X, Y, Z)` を取得できます。

ただし、**3Dデータを取得しただけで、画像が自動的に真上視点になるわけではありません。**

取得した点群を、目的に合った座標系へ変換し、仮想的な真上視点へ投影することで、透視投影によるスケールや形状の変化を軽減できます。

## 4. 正射影（Orthographic Projection）の考え方

正射影では、投影方向に沿った距離の違いによって画像上の倍率が変わらないように表現します。

例えば、作業台を基準とした座標系に変換した点群から、作業台に平行なX・Y座標を使って画像を作成します。

```text
通常の撮影画像（透視投影）
       ↓
Stereo miniでXYZ点群を取得
       ↓
作業台基準の座標系に変換
       ↓
X・Y座標を一定のmm/pixelで画像化
       ↓
真上視点に近い正射影画像
```

これにより、視野の中心と端にある同じ寸法の部品を、原則として同じ画像スケールで比較できます。

### 注意：正射影と形状復元は別

正射影は投影の幾何学的な歪みを抑える方法であり、隠れている面を復元する処理ではありません。側面の点も投影されるため、**上面だけの輪郭が必要なら高さ条件や平面分離による抽出**が必要です。

## 5. ステレオカメラでも解決できないこと

| 現象 | 3Dデータによる対応 |
|---|---|
| 視野位置による画像倍率の違い | 正射影で軽減できる |
| 斜め視点による輪郭の変形 | 3D座標を使った再投影で軽減できる |
| 物体の側面が見える | 側面は依然として観測される。必要に応じて分離する |
| 裏側・遮蔽された部分が見えない | 1方向からの撮影では復元できない |
| 金属反射や透明物による深度欠落 | 正射影だけでは改善しない |
| 点群の測定誤差 | 校正や測定条件の確認が必要 |

つまり、**「どこから見ても同じ形に写る」のではなく、「測定した3D座標から共通の見方へ変換できる」**という理解が正確です。

## 6. Pythonでの物体位置検出への応用

現在の撮像プログラムでは、XYZ座標をNumPy配列として取得しています。

```python
xyz = capture_xyz(camera)

x = xyz[:, :, 0]
y = xyz[:, :, 1]
z = xyz[:, :, 2]
```

この配列を利用して、次の順序で物体検出を実装する方針が考えられます。

1. **有効点の抽出**：NaN・Infや測定範囲外の点を除外する。
2. **作業台の基準面を求める**：必要なら平面を推定し、座標系をそろえる。
3. **物体を高さで分離する**：作業台から一定以上の高さにある点を抽出する。
4. **正射影画像を生成する**：作業台平面上のX・Y座標を一定のmm/pixelで画像化する。
5. **OpenCVで物体領域を検出する**：二値化、輪郭抽出、連結成分解析などを利用する。
6. **位置を算出する**：物体領域に対応する3D点群から中心位置などをmm単位で求める。

例えば正射影画像を **0.2 mm/pixel** で生成すれば、画像上の10画素は作業台平面上の2mmに相当します（座標変換と校正が適切である場合）。

### 深度BMPよりXYZ配列が適している理由

現在のBMPはZ座標を8bitグレースケールに変換した**表示用画像**です。距離値が量子化されるため、精密な位置計算には元のXYZ配列を使う方が適しています。

## 7. 実用上の確認ポイント

- カメラ座標と作業台座標を混同しない。
- 正射影の画素スケール（mm/pixel）を一定にする。
- 側面を含めるか、上面だけを抽出するかを先に決める。
- 視野の中心と端に同じ部品を置き、検出位置・寸法の差を実測する。
- 隠れた部分や深度欠落は、正射影では補えないことを前提にする。

## 8. まとめ

通常の2Dカメラは、視野の中心と端で同じ物体の見かけの形状が変わりやすくなります。ステレオカメラも撮影そのものは透視投影ですが、取得した3D座標を使って作業台基準の**正射影画像**を作れば、その差を抑えられます。

物体の位置検出では、**Stereo mini → XYZ点群 → 作業台座標への変換 → 正射影 → OpenCVによる検出**という流れが有力です。

ただし、正射影は見えない面を復元するものではなく、側面・遮蔽・深度欠落への対策は別途必要です。
